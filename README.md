# magpie-hud

使用 **Tauri 2 + 系统 WebView** 构建 Windows 独立悬浮窗。完成用量只读 Magpie 的 `usage.jsonl`，进行中状态只读本机网关 `/v1/magpie/trace` 与 `/v1/magpie/concurrency`；显示会话名称、流动路由及本次 Token/TPS，底部默认显示两行带本地时间的说明，高度不超过 420px 时收为 28px 单行。不修改 Magpie、不读取密钥、不集成进 rs_agent_router。

**当前状态：支持自由缩放、横竖布局、实时路由、账号额度和费用估值。** 标题为 Magpie HUD，主背景 50% 不透明度配合 Windows Acrylic 磨砂，文字保持清晰。横窗来源不超过两个时与 Magpie 纵向排列；竖窗并排，保留来源图标并放大 Magpie。默认窗口 1120×400；拖动边缘/角落调整宽高，长宽比小于 1.25 或宽度小于 680px 时自动使用纵向布局；来源超过两个且宽度小于 980px 时也使用纵向布局。统计、来源与会话块随尺寸重排；高度不超过 420px 时，统计精简为 `Token | TPS | 费用`，日志收为 28px 单行，拉高后自动恢复。完整需求见 [SPEC](docs/spec/magpie-route-float-SPEC.md)，2026-10-20 的会话/统计增量见 [M2 档案](docs/feat/Feat_261019_2_分流图与托盘.md)。原始 [HTML 原型](docs/ui/magpie-hud.html) 保留为早期设计参考，实际程序使用 `ui/index.html`、`ui/hud.css` 和 `ui/hud.js`。

## 运行

需要 Rust stable、Windows 10/11 WebView2 Runtime 和 **Tauri CLI 2**。本机已于 2026-10-20 确认安装 `tauri-cli 2.12.3`，替换原来的 1.6.1。

首次安装 CLI：

```bash
cargo install tauri-cli --version "^2.0.0" --locked
```

在项目根目录启动开发窗口：

```bash
cargo tauri dev
```

构建发布包（本次尚未执行）：

```bash
cargo tauri build
```

运行 Rust 单元测试：

```bash
cargo test --manifest-path src-tauri/Cargo.toml --lib
```

默认读取 `%USERPROFILE%\.config\magpie\usage.jsonl`，配置位于 `%APPDATA%\magpie-hud\config.json`。配置字段为 `usageJsonlPath`、`magpieHost`、`window` 和 `alwaysOnTop`；`magpieHost` 是实时数据的网关地址，只允许本机回环 HTTP（例如 `127.0.0.1:3425`），绕过代理、不跟随重定向。窗口尺寸随位置保存，重启不强制恢复宽模式。置顶按钮控制窗口置顶，隐藏按钮把窗口隐藏到托盘；托盘菜单提供显示、隐藏和退出。

日志在请求结束后写入，≤500ms 的刷新目标从完整记录落盘开始计算。启动以 64KB 分块流式汇总本地当日记录；运行中只读新增字节，半行留到完整后再处理。`kind=routing` 的内部分类调用不计入统计，重复行不重复累计。

## 会话、状态与当日统计

- 右上“最近会话”显示全部进行中会话，再用最近完成会话补足三个；超过三个活跃会话时全部显示。旧完成会话被挤出默认视图后仍可从下拉列表选择，不按秒超时删除。仅实时存在而尚无完成日志的会话，结束/断线到日志落盘之间可能短暂消失；本地跨日或日志轮转重建会移除旧记录。选具体会话后同步路由、用量、底部说明及当日统计。会话名称读取 Desktop 本地元数据与 Codex `session_index.jsonl`，按完整 ID 映射；缺名称显示“未命名会话”，缺 ID 为“未标记会话”，完整 ID 仅保留在提示与分组身份中。
- 路由块主行显示会话名和状态，次行显示模型、账号与强度，旁边是本次 Token/TPS。强度 low、medium、high、xhigh、max、ultra 分别为浅蓝、绿、黄、橙、粉红、淡紫红，未知值保持中性。请求进行中与排队显示蓝色“虚线圆＋运行中”，成功和重试成功均显示绿色“√ 已完成”，取消显示红色“x 已取消”，服务失败显示红色“x 失败”，未知状态显示红色“x 状态未知”；原始错误、HTTP 状态和完整说明保留在悬停提示。完成即停止动画；减少动态效果时保持静态状态。统计 Token、TPS 与费用分别以浅蓝、青绿和暖金区分。
- 失败使用真实 HTTP 状态及错误；499 为调用方取消，不算账号冷却。后续成功或 `tries>1` 时统一显示“已完成”，重试与恢复依据保留在提示和底部说明中。`usage.jsonl` 不含路由页的逐次失败账号、实时冷却和精确恢复时间，不能复刻“31 秒后恢复”倒计时。
- **Token**：按系统本地日期汇总 `in + out + cache_read`。日志中的 `t` 是请求开始时间；当天归属按该时间转本地日期，最新完成和恢复顺序按文件追加顺序，避免并发请求倒序。
- **费用估值**：只读 Magpie `/v1/magpie/usage?period=today` 的 USD 估值和未定价条数，选中会话时按 `sessions[].id` 显示该会话费用，每 5 秒刷新。订阅账号金额为等价用量估值，并非实际账单；费用沿用 Magpie 用量页口径（含内部 routing），而 HUD 的 Token/请求数排除 routing。无价格不伪造 $0.00，日志 Credits、账号余额各保留自身单位。
- **用量**：左栏第二部分读取 `/v1/magpie/quotas?kept=1` 的最近缓存额度，启动立即读取，之后每分钟更新；新请求完成后合并 2 秒内的完成事件补刷一次。保留上次读数，不为未匹配账号或“正在选择账号”绘制空进度条。当前显示会话中，实际选中的供应商和完整账号会显示额度。自动分流时，外层分组供应商不参与额度匹配。5h、周等窗口没有模型限定时属于账号共享额度。显示为两行：账号与重置倒计时（例如 `5d2h`、`5h2m`、`32m`，悬停可看准确重置时间）；窗口简称、已用进度条与百分比。账号放不下时自动省略，悬停可看完整账号；左栏不显示滚动条，超长列表仍可用滚轮查看。详细模型、读数时间和错误放在悬停提示，失联保留旧读数并标记。
- **TPS**：最近 10 个会话的加权输出速度 `Σout / Σ(ms − ttft_ms) × 1000`，仅纳入成功且生成耗时有效的记录；选中单个会话时只显示该会话。每块会话另显示本次请求对应的 Token/TPS。Magpie 活跃接口尚无执行中的精确输出计数，进行中显示“待统计 Token / — TPS”，完成日志到达后显示最终值；`upstream` 包含等待首字与正在流式返回，不伪造逐 Token 进度。
- 模型图标来自 [LobeHub Icons](https://github.com/lobehub/lobe-icons) 的 `@lobehub/icons-static-svg` 1.95.1，已本地打包并保留 [MIT 许可](ui/icons/LICENSE)，应用运行时不联网加载图标。
