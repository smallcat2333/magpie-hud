## 1. 目标
### 1.1 优化对象与动机
处理 issue 17：Desktop/CLI/自定义标题与子 Agent 元数据扫描在 concurrency 请求之前串行执行，慢文件读取会拉长活跃状态刷新间隔。Codex session_index.jsonl 每次全读。

### 1.2 验收阈值（量化）
- 100,000 行、1,000 个 ID 的脱敏 Codex 索引，同机 release，三组各 5 次无变化扫描取中位：耗时至少降低 90%，内容读取字节数降为 0。
- 单条追加只读取新增字节与最多 512 字节校验锚点，不全量读取。
- 每轮 Codex 内容读取预算最多 1 MiB，校验锚点另计最多 512 字节；单行缓冲最多 64 KiB。
- 标题扫描通过同步通道阻塞至少 600ms 时，实际 Runtime 并发活动更新仍在 100ms 内完成，扫描发布不覆盖更新后的活动状态。
- 保持完整 ID、标题优先级、Desktop 显式别名及子标签口径；覆盖半行、超长行、坏行、追加、截断、等长覆盖和文件替换。
