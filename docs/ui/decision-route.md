# 路由决策

判定栏显示 Magpie 已记录的有序路由过程，例如：`自动〔jev-latest〕 → 干活〔jev-latest〕 → gpt-6-astra〔尝试1〕`。宽窗位于右侧会话栏底部，高度为 76px；窗口高度不超过 540px 时为 56px。左侧统计保持完整高度。

## 节点和详情

- 组节点：组名和判定模型，例如 `jev-latest`；沿用轮初结果时显示 `沿用 jev`（该记录含模型名称时）或 `沿用轮初`。第二行显示规则编号、用户轮次与判定强度。规则编号 0 表示未命中，缺失编号表示未记录。候选的基础排序策略收纳在详情中；无规则记录时显示 `候选按顺序` 等策略标签。
- 判定来源：实际分类模型使用模型族图标；沿用轮初判定使用金色回返箭头与确认勾；未记录分类模型使用紫色文档图标。已知分类模型没有对应图标时使用通用模型图标。
- 判定耗时：显示在该组右侧连线的上方，文字在节点高度 1/3 处水平及垂直居中，少于一秒显示 `224ms`，达到一秒显示 `1.22s`；小于 1 秒为绿色，1 秒至不足 2 秒为黄色，达到 2 秒为红色。读取 `classified.ms`，表示 Magpie 判定函数整体耗时。缓存显示 `jev 缓存` 并在详情中说明；沿用轮初、轮初判定缺失及未记录耗时时不补零或显示旧耗时。
- 实际尝试：按 `tries` 顺序显示模型与尝试结果。底部状态可区分等待并发空位、等待速率额度、等待路由切换、请求中和首字状态未确认。
- 悬停或键盘聚焦节点：查看完整意图、置信度、判定来源、规则优先目标、替代目标记录、候选计划和此前尝试。按 Esc 关闭详情。
- 悬停或聚焦会话卡：显示该会话及对应子 Agent 的判定；移开后恢复当前路线。没有对应记录时明确显示空状态。

## 连线与动画

连线按已确认的组层级和实际尝试顺序连接，高度位于节点从上往下 2/3 处。规则记录不表示所有规则并行执行。每段连线第一次确认经过时播放至少 1 秒的向右光点，随后变为绿色实线并停止光点，即使执行模型仍在请求中也不继续流动；尚未确认经过的部分保持浅灰。快速完成的请求也保留这 1 秒展示。重复快照不会重置或重播动画，动画不代表判定模型仍在运行。系统开启减少动态效果时直接显示确认状态，不播放光点。

## 数据边界

组链按组 ID/ref 和父子关系确认；无法唯一确定的后续路径标记未确认。规则 `use` 是优先目标，不能代替实际尝试模型；计划 `order` 收纳在详情中，不能当作已发生的尝试。首字等待时间超过 15 秒只表示状态尚未确认。账号、凭据和原始规则表达式不包含在判定投影中。
