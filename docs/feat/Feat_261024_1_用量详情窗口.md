# 用量详情窗口

## §1 需求与范围

用户于 2026-10-24 确认方案并授权实施。双击 HUD 六项统计共用一个可调整大小的详情窗口，携带当前日期、Agent / 网关密钥和具体会话，切换入口唤起已有窗口。详情筛选不反向影响 HUD。

支持日期区间、模型、供应商 / 账号、强度、Agent / 来源多选；时间趋势、分组对比、重置周期；分组和逐次请求明细。TPS、缓存率、均次费用从累计量加权。未知费用不分摊、无周期边界不倒推成事实。仅只读本地日志及 loopback HTTP，无代理、重定向、TLS、凭据或请求正文，不修改 Magpie。

## §2 界面与口径

- 单实例窗口约 960×720，可缩放、最大化。顶部产品名与范围筛选；六项指标共享一条导航；中间图表，下方可排序分页明细。
- 沿用 HUD 字体和蓝色数据色；2026-10-24 按用户反馈改为与 HUD 相同的原生 Acrylic 和 50% 底色，数字保持不透明。页面、表格、指标横滚和下拉选项隐藏滚动条，保留滚轮/触控板滚动；窄窗筛选折叠、指标横滚、表格内部横滚。
- 来源身份沿用 canonical Agent + 密钥 ID（无 ID 用原名称），最新密钥名称仅作显示，缺失显示本机。
- 请求按本地开始日期；已完成记录排除 routing、缺 session、重复身份与不完整行。
- 费用采用 `/v1/magpie/usage/requests` 的逐请求 `cost` / `priced`，按本地日志复合身份与会话/输入/输出/缓存用量核对后关联；模型、账号、强度、来源、时间、周期任意交叉条件都累加选中请求的金额。未定价/未匹配/冲突保持未知，不分摊合计。费用旁显示覆盖数。
- 重置周期从同一日志目录下 quota-history.json 的明确 start/resetsAt 读取，按供应商、账号、窗口分别列出；不把滚动读数伪装成固定周期。额度为最近观测值，不宣称期末最终消耗，HUD 请求统计与供应商额度分开。
- 日期筛选与周期取交集，可查看完整周期；边界缺失、历史缺失与读取失败明确呈现。
