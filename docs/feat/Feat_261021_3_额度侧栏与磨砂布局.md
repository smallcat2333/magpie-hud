## 5. 会话出现/消失规则

- 每次快照由当天完成日志重建，再覆盖实时活跃请求。会话身份为完整 ID；无 ID 的记录合并为“未标记会话”。
- “最近会话”显示所有 running/waiting 会话，再按实际窗口可用高度用最近完成会话补足，至少三个；竖窗计算时扣除统计、额度与来源区。活跃会话全部保留，区域可滚动。选定会话时仅显示该会话。
- 完成会话不会按秒超时删除；被较新会话挤出最近视图后仍可从下拉选择。下拉保留所有当天会话。
- 当天尚无完成日志的临时会话，仅存在于活跃快照。活跃结束/中断且日志未落盘时可以短暂消失；完成日志到达后恢复。中断提示明确保留的只是完成记录。
- 当地跨日、日志轮转重建会清除不属于新账本的完成会话；关闭 Desktop 会话本身不等同从 usage 日志删除。
- 每个会话保留最新完成请求与仍失败的旧账号；同账号后续成功替换失败，实时阶段覆盖旧成功卡，最多显示四张路由卡。
