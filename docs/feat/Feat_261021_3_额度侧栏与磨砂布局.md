## 1. 需求

横屏来源不超过两个时，请求来源与 Magpie 在同一列上下排列；左侧统计区下方增加用量，显示当前可见会话所用账号/模型的最近 5h、周等额度。竖屏来源与 Magpie 并排，保留来源图标并放大 Magpie 标志。标题统一为 Magpie HUD，背景透明度 50%，使用原生磨砂玻璃。显示 Magpie 能统计的费用，low、medium、high、xhigh、max、ultra 六档强度分别着色。说明会话出现与消失的依据。

## 2. UI 与数据约定

保留现有石墨底色、洋红路由和系统中文字体。左栏分当日统计、用量两段；小高度时压缩统计排版，额度列表超长可滚动。竖屏顶部保留统计与用量，再放来源/Magpie 和会话。50% 仅作用于主背景，文字独立保持不透明；Tauri Acrylic 模糊窗口背后的桌面，CSS blur 负责浏览器内的背景。

强度使用浅蓝、绿、黄、橙、粉红、淡紫红，保留完整文字，未知强度保持中性。用户明确要求磨砂与六档颜色，优先于设计技能中禁止 glass、多色的默认建议。参考 Data terminal（seed 1919189929），保留本项目路由图与既有布局，不套用导航/部署页模板。

额度只读 `/v1/magpie/quotas?kept=1`，每 30 秒读取 Magpie 已缓存的供应商读数，不额外触发供应商查询。按 provider + 完整账号唯一匹配，重复或缺失身份不猜测。同一账号的多个模型合并关联，每个额度窗口显示两行：账号与重置时刻；窗口简称（5h/周）、已用进度条与百分比。模型、共享范围、读数时间和错误详情保留在悬停提示，不占正文；旧读数保留简短标记。无比例时用空虚线轨道与破折号，不能伪造 0%；余额仅在提示显示。切换会话同步额度范围。

2026-10-21 视觉微调：统计 Token / TPS / 费用分别用浅蓝 / 青绿 / 暖金，深色表面对比度均大于 10:1。进行中卡片以旋转虚线圆代替“请求中”文字，保留可访问名称和提示；动画以时间同步相位，刷新不反复归零，减少动态时停转，完成后移除。

费用只读 `/v1/magpie/usage?period=today`，每 5 秒刷新，使用 Magpie 定价后的 USD 估值和 unpriced 覆盖数据。选中会话使用 sessions[].id 精确映射，不把全局金额分摊给会话。全部未定价时显示未定价，真实零金额仍显示 $0.00。Magpie 费用含内部 routing 调用；HUD Token/请求数排除此类调用，因此在费用提示说明不同口径。订阅的等价金额不是实际账单，Credits 与余额不冒充 USD。

## 5. 会话出现/消失规则

- 每次快照由当天完成日志重建，再覆盖实时活跃请求。会话身份为完整 ID；无 ID 的记录合并为“未标记会话”。
- “最近会话”显示所有 running/waiting 会话，再用最近完成会话补足三个。超过三个活跃会话时全部显示，区域可滚动。选定会话时仅显示该会话。
- 完成会话不会按秒超时删除；被较新会话挤出最近视图后仍可从下拉选择。下拉保留所有当天会话。
- 当天尚无完成日志的临时会话，仅存在于活跃快照。活跃结束/中断且日志未落盘时可以短暂消失；完成日志到达后恢复。中断提示明确保留的只是完成记录。
- 当地跨日、日志轮转重建会清除不属于新账本的完成会话；关闭 Desktop 会话本身不等同从 usage 日志删除。
- 每个会话保留最新完成请求与仍失败的旧账号；同账号后续成功替换失败，实时阶段覆盖旧成功卡，最多显示四张路由卡。
