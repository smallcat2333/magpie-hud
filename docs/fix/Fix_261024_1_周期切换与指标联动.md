# Fix_261024_1 周期切换与指标联动

> 状态：已验证待确认
> 应用：magpie-hud
> 创建：2026-10-24　　关闭：-

## 1. 现象
### 1.1 问题描述
用户反馈用量详情重置周期第二次切换像卡住；顶部选择费用后，周期表仍固定显示 Token。

### 1.2 复现步骤
1. 进入用量详情，选择重置周期。
2. 连续切换周期行、上一/下一周期、账号与额度窗口，以及时间趋势/重置周期页签。
3. 选择费用估值，检查每个周期数值、单位及费用覆盖。

### 1.3 影响范围
详情窗口周期选择与指标展示；不修改 Magpie 或真实用量记录。

## 2. 根因分析
- 2026-10-24：模拟数据浏览器复现顶部费用选中、周期表仍为 Token。renderCycles 的标题和数值硬编码为 Token。
- 账号下拉每次 render 都销毁全部 option，即使列表不变。已确认 DOM 身份变化；尚未稳定复现原生 WebView2 第二次点击冻结，不能把平台弹层异常当作确定根因。
- 周期行仅时间文字内按钮响应点击，数值/状态区域不响应；选择以对象引用判等，同日期刷新替换数据后会回到第一周期。

**根因**：指标未联动、周期点击范围过小和刷新后对象身份变化已定位；下拉重建与原生卡住的直接因果仍为猜测。
**确信度**：已定位到根本原因（指标/点击范围/刷新选择）；这是猜测（下拉弹层冻结）。

## 3. 修复方案
- ui/details.js：周期选项列表变化时才同步；按字段身份保留周期，整行可选；周期表展示所选指标、单位及费用覆盖。
- ui/details.html：更新脚本资源版本。

## 4. 验证记录
- 2026-10-24：`node --check ui/details.js` 与 `node tests/details-data.cjs` 通过。
- Browser preview，独立合成数据（两个账号、三个五小时周期）：8 轮整行/上一/下一/页签往返切换、10 次账号切换通过；同范围刷新返回全新对象后保留选中周期，option DOM 身份保留。
- 六指标列名/单位/列数联动通过；三个周期费用分别 0.25/0.50/0.75 美元，未定价账号保持未知“—”，覆盖 0/1；费用数据未分摊。
- 1000px 截图确认费用列与覆盖；480px 页面无横向溢出（scrollWidth=480），周期表内部可滚动；浏览器控制台无错误。
- 限制：原用户报告的原生 WebView2 第二次点击冻结未能在浏览器稳定复现；相关确定问题已修复，下拉重建已消除。随 v0.0.29 一并提交，桌面运行版本随后更新。
